## 📊 STRUCTURE CLÉS

### **Données (JSON)**
```json
{
  "id": 1,
  "nom": "Nom Complet",
  "titre": "Miss [Titre]",
  "annee": 2025,
  "photo": "images/photo.jpg",
  "description": "Courte",
  "biographie": "Complète",
  "parcours": "Détails",
  "engagements": "Causes",
  "citation": "Inspirante",
  "reseaux": { "facebook": "...", "tiktok": "...", "instagram": "..." }
}
```

### **Pages**
- `toutes-les-miss.html` - Listing avec filtres
- `miss-detail.html?id=X` - Profil complet

### **Scripts**
- `misses.js` - Gère tout automatiquement
