📊 Données JSON

Le fichier data/misses.json contient:

  • 15 miss définies avec tous les champs
  • IDs: 1 à 15
  • Champs: id, nom, titre, année, photo, description, biographie, parcours, engagements, citation, réseaux

Pour ajouter une new miss:

  1. Ouvrir data/misses.json
  2. Ajouter un nouvel objet miss avec un ID unique
  3. Remplir tous les champs requis
  4. Sauvegarder le fichier
  5. La mise à jour est immédiate!

📝 Notes Importantes

  • JSON invalide: Si data/misses.json a une erreur de syntaxe, le système affichera un message d'erreur. Utilisez jsonlint.com pour valider.
  • Images manquantes: Si une image n'existe pas, elle affichera un placeholder vide. Vérifiez les chemins dans le JSON.
  • Cache du navigateur: Si vous modifiez le JSON, videz le cache du navigateur (Ctrl+Shift+Delete) pour voir les changements.
  • CORS: Si vous servez les fichiers en local avec file://, le JSON ne se chargera peut-être pas. Utilisez un serveur local.
